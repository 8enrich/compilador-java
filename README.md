# JavaPy

JavaPy é um projeto de compilador Java escrito em Python, sendo desenvolvido para
a cadeira de compiladores do curso de ciências da computação, por enquanto
contém apenas a parte de análise léxica.

----------

### Como rodar

- Clone o repositório:

```bash
git clone https://github.com/8enrich/compilador-java.git
```

- Entre na pasta:

```bash
cd compilador-java
```

- Execute algum arquivo:

```bash
python3 javapy.py <java-file>
```

----------

### Rodando os testes:

Existem alguns arquivos de teste na pasta /java-files, para rodar faça:

```bash
python3 test.py
```
